# 案例：一人用 Creao 搭 HBM 存储股监控 Agent

## 背景

SKHY（海力士 ADR）今天正式在纳斯达克开始交易。这是近年来规模最大的 ADR 之一，7倍超额认购说明市场对 HBM 的兴趣极强。与此同时，MU（美光）和 SNDK（闪迪）也在同一条主线上波动。

很多散户想盯着这几只股票，但不知道怎么做到「有信号就收到提醒、不用一直盯盘」。

## 我做了什么

我在 Creao 上用不到两个小时，搭了一个 HBM 存储股监控 Agent。

我描述了我想要的效果：

> 帮我盯 MU、SNDK、SKHY 这三只股票。如果任何一只在开盘后单日涨跌超过 5%，或者成交量突然暴增到 3 倍以上，立刻给我发提醒，并附上一句话说明是什么情况。

Creao 自己搞定了数据接入、阈值逻辑、通知推送的整个流程。我没有写一行代码。

## 为什么选这个案例

- **时效性强**：SKHY 刚上市，HBM 是目前美股最热的主线之一
- **需求真实**：很多跟踪 AI 存储链的人都需要这个，但不知道怎么做
- **一人可完成**：从想法到跑通，不到两小时，一个人干完

## Creao 在这里的作用

Creao 的 Agent 机制解决了三个问题：

1. **数据接入**：不需要自己对接行情 API，Creao 帮你处理
2. **逻辑执行**：描述条件，Agent 自己判断触发时机
3. **持续运行**：Agent 设置好之后 24 小时自己跑，不需要人守着

## 适合谁

- 想盯着某个板块但不想一直看盘的个人投资者
- 跟踪 AI 基础设施、HBM、半导体板块的内容创作者
- 想把「关注清单」变成「自动提醒系统」的一人团队

## 关键结论

这不是「用 AI 选股」。这是把你自己的判断逻辑，交给 Agent 去执行监控这一步。判断还是你来做，Agent 负责不让你错过信号。
